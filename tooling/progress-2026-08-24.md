## Key changes this session

1. **Wired the full service router** (`src/router.rs`) into `server.rs::extract_service()` — SQS requests now route correctly via X-Amz-Target, auth scope, and host header.
2. **Fixed missing Host header** — axum strips Host from HeaderMap; recovered from `uri.authority()` so the router's virtual-host checks work.
3. **JSON body parsing** — `server.rs` now parses JSON request bodies (content-type based), not just form-encoded. SQS uses `application/x-amz-json-1.0`.
4. **Fixed STS panic** — `StsFunctionHandler` created a nested tokio runtime inside an async context (panics). Now polls the future directly with a noop waker.
5. **SQS crate** (W1): added SetQueueAttributes, ChangeMessageVisibility, PurgeQueue; CreateQueue applies Attributes; ListQueues supports QueueNamePrefix; GetQueueAttributes adds LastModified/NotVisible/Delayed counts.
6. **Golden harness** (W2): `scripts/harness/golden_test.py` (replay + diff) and `scripts/harness/botocore_check.py` (17-step smoke test). Diff now matches by op name so partial captures work.
7. **Clippy fixes** across pre-existing files (account, spec, signing, cors, router, s3_routing, state).

## Known gaps (next work)

- **S3** — no Rust S3 service. The router detects S3 requests but the registry has no handler.
- **SQS batch ops** — SendMessageBatch, DeleteMessageBatch, ChangeMessageVisibilityBatch.
- **SQS FIFO** — .fifo queues, MessageGroupId, dedup.
- **SQS long polling** — WaitTimeSeconds not implemented (always non-blocking).
- **SQS tags** — TagQueue, UntagQueue, ListQueueTags.
- **SQS DLQ** — redrive policy, ListDeadLetterSourceQueues.
- **Other services** — DynamoDB, SNS, Lambda, etc. are all unimplemented in Rust.
- **Health endpoint** — still reports only `sts` in the services map; should reflect all registered services.
- **Persistence** — state is in-memory only (matches Python default).
